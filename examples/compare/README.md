## 三、效果图分类说明

每个案例目录下的文件约定：

| 文件 | 含义 |
|------|------|
| `source.png` | **原始设计稿**（输入） |
| `rendered.png` | **生成效果图**（生成代码在浏览器渲染后的截图，1440×900） |
| `diff.png` | **像素差异图**：原图 vs 渲染图逐像素比对，**红色区域 = 不一致像素**，红色越多差异越大 |
| `code.html` / `code.tsx` | 生成的源代码（可直接打开或集成） |
| `validation.json` | 校验数据：相似度、差异区域坐标、DOM 布局快照、文字覆盖率等 |

### 如何读效果图

1. 先看 `source.png`（设计原稿），再看 `rendered.png`（生成效果）——直观对比还原度
2. 看 `diff.png` 定位失分区域：红色集中在**照片/插画区域**属正常（CSS 无法还原照片），若红色出现在**布局/文字区域**则说明结构有偏差
3. 打开 `code.html` 可直接在浏览器验证交互与响应式

## 五、附：测试中发现并处理的问题

1. **LLM 超时与流式改造**（已修复并生效）
   - 非流式请求总超时 300s（`LLM_TIMEOUT_MS`）
   - 流式请求：总超时 900s（`LLM_STREAM_TIMEOUT_MS`）+ 空闲超时 120s 无数据即中止（`LLM_IDLE_TIMEOUT_MS`，每收到数据自动重置）
   - `chatCompletion` 已默认改为流式调用
2. **上传图片 4MB 硬限制**（已生效）：本地路径与 base64 双重校验，超限返回 `IMAGE_TOO_LARGE`
3. **缓存 Bug（待修复）**：`job-service.ts` 的 `performRestore()` 重启后用**当前模型配置**重算历史任务缓存 key，导致换模型后仍返回旧结果，且缓存命中产生的新任务会自我延续。建议在 `input.json` 持久化任务当时的 `modelConfig`，restore 时使用任务自身配置计算 key。
4. **模型权限**：`qwen3.8-27b` 曾一度返回 `AccessDenied.Unpurchased`，开通后已恢复可用，并成功完成电鸭对比测试（92.51%）。
